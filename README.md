# SOUND · расширение Microsoft Edge

Переключение звука управляемых вкладок между двумя выбранными аудиовыходами и независимая громкость каждой вкладки. Manifest V3, без сервера, внешних библиотек, аналитики и удалённых ресурсов.

## Установка

1. Скачайте и распакуйте архив расширения либо используйте эту папку репозитория.
2. Откройте `edge://extensions`, включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку, содержащую `manifest.json`.
4. Закрепите SOUND на панели расширений.
5. Откройте настройки SOUND, нажмите «Найти аудиоустройства» и разрешите доступ к микрофону для обнаружения названий устройств. Поток микрофона сразу останавливается, не записывается и не передаётся.
6. Выберите два разных аудиовыхода, задайте удобные названия и сохраните.
7. Откройте обычную вкладку с музыкой/видео, нажмите SOUND и выберите карточку «Наушники» или «Динамики». Расширение само подключит звук текущей вкладки; появится регулятор её громкости.
8. Переключайте устройство нажатием на нужное устройство или `Alt+Shift+S`. Клавиши можно изменить в `edge://extensions/shortcuts`.

Требуется актуальный Edge на Chromium 116 или новее. Оба устройства должны быть подключены и доступны браузеру. При первом использовании браузер может запросить разрешение на вывод аудио.

## Границы возможностей

- Меняется выход захваченных вкладок, а не системное устройство Windows и не звук других приложений. Для системного переключения требуется отдельный native-компонент, в этой версии его нет.
- Браузер требует явного действия пользователя для начала захвата вкладки. Расширение не включает захват автоматически.
- Громкость 0–100% умножается на громкость самого плеера. Отключение управления освобождает захват, возвращая обычное воспроизведение вкладки.
- Захват живёт в offscreen-документе и продолжается после закрытия всплывающего окна. Закрытие вкладки или перезапуск браузера требует повторного включения управления.
- Служебные страницы, некоторые DRM-плееры и другие защищённые источники могут запрещать захват.
- При отключении устройства браузер может временно вернуть вывод на системный выход. Переподключите устройство и проверьте пару в настройках.
- Разрешение `tabs` нужно для списка и названий вкладок; `tabCapture` — для аудиопотока; `offscreen` — для воспроизведения в фоне; `storage` — для сохранения пары. Данные хранятся локально.

## Разработка и проверки

Используйте существующий checkout; отдельный worktree не требуется. Node.js 18+ нужен только для проверок, зависимости устанавливать не нужно.

```sh
npm test
npm run check
```

После правок перезагрузите расширение на `edge://extensions` и снова включите управление нужными вкладками.

Перед повседневным использованием проверьте в Edge: две одновременно играющие вкладки; независимую громкость и mute; переключение между физическими устройствами кнопкой и клавишами; продолжение звука после закрытия popup; возврат обычного звука после «Отключить»; закрытие вкладки и отключение устройства. Автотесты модели и аудиодвижка не заменяют проверку реального оборудования.

## Обновление до 1.1.0

Замените файлы установленного расширения содержимым свежего ZIP, затем нажмите «Обновить» на карточке SOUND в `edge://extensions`. Если Edge отключил расширение из-за нового разрешения activeTab, подтвердите его включение. В popup теперь две отдельные карточки выходов. Не требуется сначала нажимать «Управлять»: выбор выхода подключает текущую вкладку автоматически. Для дополнительных вкладок откройте каждую из них и выберите выход либо используйте «Управлять».
